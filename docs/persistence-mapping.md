# Persistence Mapping

This document maps the advocate-only API models to the local PostgreSQL schema.
Clerk APIs and clerk tables are intentionally not part of this project.

The tables are created in the `public` schema of the `digit_assignment`
database through Flyway migrations under `src/main/resources/db/migration/main`.

## Mapping Rules

- `Advocate` is the only persistent domain entity in scope.
- `documents` use a child table because one advocate application can have many documents.
- `auditDetails` is flattened into audit columns on the parent table.
- `additionalDetails` is stored as `JSONB`.
- `workflow` is not stored as domain data. It is sent to Workflow v2.
- Request, response, search-criteria, pagination, and API metadata models are not persisted.
- Master-data values such as `advocateType` are stored as codes only.

## `eg_advocate`

Source model: `Advocate`

| JSON path | SQL column | SQL type | Constraint/default | Search/index use | Persister JSON path |
|---|---|---|---|---|---|
| `advocate.id` | `id` | `VARCHAR(64)` | Primary key, generated UUID | Search by ID | `$.advocate.id` |
| `advocate.tenantId` | `tenantid` | `VARCHAR(128)` | `NOT NULL` | Tenant-scoped indexes | `$.advocate.tenantId` |
| `advocate.applicationNumber` | `applicationnumber` | `VARCHAR(64)` | `NOT NULL`, generated by IDGen | Unique with tenant | `$.advocate.applicationNumber` |
| `advocate.barRegistrationNumber` | `barregistrationnumber` | `VARCHAR(64)` | `NOT NULL` | Search by Bar registration number | `$.advocate.barRegistrationNumber` |
| `advocate.advocateType` | `advocatetype` | `VARCHAR(64)` | `NOT NULL`, MDMS code | None currently | `$.advocate.advocateType` |
| `advocate.organisationID` | `organisationid` | `VARCHAR(64)` | Nullable | None currently | `$.advocate.organisationID` |
| `advocate.individualId` | `individualid` | `VARCHAR(64)` | `NOT NULL` | Search by individual ID | `$.advocate.individualId` |
| `advocate.status` | `status` | `VARCHAR(64)` | Nullable until Workflow is integrated | Search by status | `$.advocate.status` |
| `advocate.isActive` | `isactive` | `BOOLEAN` | `NOT NULL DEFAULT TRUE` | None currently | `$.advocate.isActive` |
| `advocate.auditDetails.createdBy` | `createdby` | `VARCHAR(64)` | `NOT NULL` | None | `$.advocate.auditDetails.createdBy` |
| `advocate.auditDetails.createdTime` | `createdtime` | `BIGINT` | `NOT NULL` | Oldest-first ordering | `$.advocate.auditDetails.createdTime` |
| `advocate.auditDetails.lastModifiedBy` | `lastmodifiedby` | `VARCHAR(64)` | `NOT NULL` | None | `$.advocate.auditDetails.lastModifiedBy` |
| `advocate.auditDetails.lastModifiedTime` | `lastmodifiedtime` | `BIGINT` | `NOT NULL` | None | `$.advocate.auditDetails.lastModifiedTime` |
| `advocate.additionalDetails` | `additionaldetails` | `JSONB` | Nullable | None | `$.advocate.additionalDetails` |

Not stored in this table:

- `advocate.documents` is stored in `eg_advocate_document`.
- `advocate.workflow` is sent to Workflow v2 and is not persisted as advocate data.

## `eg_advocate_document`

Source model: each item in `Advocate.documents`

| JSON path | SQL column | SQL type | Constraint/default | Search/index use | Persister JSON path |
|---|---|---|---|---|---|
| `document.id` | `id` | `VARCHAR(64)` | Primary key, generated UUID before persistence | None currently | `$.id` |
| Parent `advocate.id` | `advocateid` | `VARCHAR(64)` | `NOT NULL`, FK to `eg_advocate(id)` | Parent lookup | Parent advocate ID |
| Parent `advocate.tenantId` | `tenantid` | `VARCHAR(128)` | `NOT NULL` | Tenant-scoped child rows | Parent tenant ID |
| `document.documentType` | `documenttype` | `VARCHAR(128)` | Nullable | None currently | `$.documentType` |
| `document.fileStore` | `filestore` | `VARCHAR(256)` | Nullable | None currently | `$.fileStore` |
| `document.documentUid` | `documentuid` | `VARCHAR(64)` | Nullable | None currently | `$.documentUid` |
| `document.additionalDetails` | `additionaldetails` | `JSONB` | Nullable | None | `$.additionalDetails` |

## Constraints And Indexes

| Table | Constraint or index | Reason |
|---|---|---|
| `eg_advocate` | Primary key on `id` | Entity identity |
| `eg_advocate` | Unique index on `(tenantid, applicationnumber)` | Application number identifies an application within a tenant |
| `eg_advocate` | Index on `(tenantid, status)` | Status and inbox searches |
| `eg_advocate` | Index on `(tenantid, barregistrationnumber)` | Advocate search criterion |
| `eg_advocate` | Index on `(tenantid, individualid)` | Advocate search criterion |
| `eg_advocate_document` | Foreign key from `advocateid` to `eg_advocate(id)` | Parent-child integrity |
| `eg_advocate_document` | Index on `advocateid` | Load documents for an advocate |

## Models Not Persisted

| Model/field | Reason |
|---|---|
| `AdvocateRequest` | API request wrapper |
| `AdvocateSearchRequest` | Temporary search input |
| `AdvocateSearchCriteria` | Temporary query filters; fields determine indexes |
| Response models | API response wrappers |
| `RequestInfo`, `ResponseInfo`, `Pagination` | API metadata |
| `workflow` | Command sent to Workflow v2 |
